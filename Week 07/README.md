# Week 7: XR Audio and Haptic Feedback

Week 7 focuses on creating immersive XR experiences through spatial audio and haptic feedback systems. This week introduces Unity Event Wrappers, spatial audio implementation, and haptic feedback using Meta SDK building blocks.


## Activities

All activities are located in the `Week 07/` directory:

- **[Activity 1](Activity%201%20-%20XR%20Poke%20and%20Spatial%20Audio.md)** - XR Poke and Spatial Audio
  - Unity Event Wrappers theory and implementation
  - Spatial Audio building block setup and configuration
  - Poke interaction systems with audio feedback
  - 3D positional audio for immersive experiences
  - Event-driven audio playback systems

- **[Activity 2](Activity%202%20-%20Haptics%20in%20XR.md)** - Haptics in XR
  - Haptic feedback theory and applications in XR
  - Haptics building block integration
  - Custom haptic file creation and implementation
  - Controller-based haptic feedback systems
  - Multi-sensory interaction design

## C# Scripts

The following C# scripts are included in the `Scripts/` directory:

- **[AudioPlayer.cs](Scripts/AudioPlayer.cs)** - Audio playback management for XR interactions
  - Simple audio control methods for Unity Event Wrappers

## Prerequisites

- Unity 2022.3 LTS or later
- Meta Quest 2 or Quest 3 device (required for haptic testing)
- USB-C cable for device connection
- Completion of Week 5 and Week 6 XR activities (required)
