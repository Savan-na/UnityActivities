# Lecture Example: XR Hiking App

This folder contains a Unity package example from the lecture demonstrating an XR version of the hiking app prototype. This example builds upon the basic prototype from Week 4 and integrates Meta's Building Blocks system for immersive XR interactions.

## Package Contents

### [Week 06 Lecture HikingExample.unitypackage](Week%2006%20Lecture%20HikingExample.unitypackage)

A complete Unity package containing:
- **XR Scene Setup**: Pre-configured scene with Meta Building Blocks
- **Advanced Scripts**: Enhanced versions of proximity and movement systems
- **XR Interactions**: Hand tracking, gesture recognition, and object manipulation
- **Building Blocks Integration**: Camera Rig, Interactions Rig, and custom transformers
- **Materials and Prefabs**: XR-optimized assets for immersive environments

## How to Use

1. **Setup your Project**: 
   - Create a new project or Scene
   - Install the openXR, package manager, and Meta SDK.
   - Double click `Week 06 Lecture HikingExample.unitypackage` to import the package contents

2. **Explore the Example**:
   - Open the imported scene (`B3.scene`)
   - Test XR interactions using hand tracking
   - Experiment with gesture recognition and object manipulation
   - Study the Building Blocks integration patterns


## Prerequisites

Before using this example, ensure you have:
- Completed Week 4 activities (basic proximity and movement systems)
- Completed Week 5 XR fundamentals
- Meta XR SDK installed in Unity
